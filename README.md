# PHC Knowledge

Plataforma de conhecimento técnico sobre PHC, destinada a recolher, organizar, relacionar, pesquisar e reutilizar conhecimento — com proveniência, evidências, relações e contexto técnico.

Integra conhecimento PHC standard com conhecimento específico de instalações e desenvolvimentos personalizados, respeitando o isolamento por organização.

## Estado atual

Repositório inicializado. O projeto `PhcKnowledgeScanner` está incluído em [`PhcKnowledgeScanner/`](PhcKnowledgeScanner/) (cópia do código versionado; sem pastas de publish nem dados locais de instalação).

A arquitetura tecnológica definitiva e a decisão sobre o que reutilizar do Scanner / `ConsoleApp` serão definidas em etapas posteriores.
