# PHC Knowledge — Protótipo do Portal

Protótipo HTML autónomo para validação da experiência visual e dos percursos principais do Portal.

## Abrir

1. Abrir [index.html](index.html) no GitHub.
2. Selecionar **Raw** e guardar o ficheiro localmente como `index.html`.
3. Abrir o ficheiro num browser moderno.

Não requer Node.js, servidor, dependências ou ligação à base de dados.

## O que está demonstrado

- Início e pesquisa global.
- Detalhe contextual de objeto PHC, com separadores.
- Capturas e estados Receive / Validate / Archive.
- Áreas conceptuais de soluções reutilizáveis e clientes/instalações.
- Administração de utilizadores.
- Navegação, tema claro/escuro e comportamento responsivo.

## Limites

- Todos os registos, contagens, nomes e exemplos são fictícios.
- Não existe ligação a APIs, autenticação, SQL Server ou Scanner.
- As ações de upload, edição e criação não executam operações reais.
- A análise prévia, confirmação de importação, associação de contexto e materialização são apresentadas como capacidades futuras.

A referência funcional e visual é [a especificação da experiência do Portal](../../architecture/portal-experience-specification-2026-11-19.md).
